# PopX 
Aim of the task is to be design a pixel-perfect, with the mobile App interface centered on the webpage. Additionally, navigation between pages should function seamlessly and efficiently.

## Tech Stack
- React.Js
- React Router Dom
- Tailwind CSS

## Folder Structure 

## Installation
1. Clone the repo
```
https://github.com/denofdhamodhar/PopX.git
```
2. After clone

```
cd PopX
npm i
```
3. Run the project
```
npm run dev
```
